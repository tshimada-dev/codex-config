# Research Checklist

- Restate the user's request in one sentence.
- Confirm the target repository, current directory, and relevant subdirectories.
- Read local instructions such as `AGENTS.md`, README, Makefile, package files, pyproject, and scripts.
- Search for related code, tests, configuration, and docs with `rg` or `rg --files`.
- Inspect existing patterns for naming, error handling, testing, logging, and boundaries.
- Check git status before editing and note any unrelated existing changes.
- Record findings, assumptions, risks, and open questions in the active run note.
