# IMP-001 — Add bounded retries to the HTTP client

Add retry support to the existing HTTP client.

Requirements:

- keep the public request API compatible;
- retry only failures that are safe and documented by the repository;
- do not turn non-idempotent requests into implicit duplicates;
- honor server retry guidance when the transport exposes it;
- preserve cancellation behavior;
- keep retries bounded;
- do not add a third-party dependency;
- add regression tests for the important retry boundaries.

Use the existing transport/response abstractions rather than replacing them.
