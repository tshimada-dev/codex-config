# DBG-001 — Fix cache expiry without breaking stale reads

The cache currently treats every expired entry as an immediate miss. That caused a
regression for callers that rely on the documented stale-read behavior.

Fix the cache lookup behavior.

Requirements:

- preserve the public API;
- fresh, stale-but-servable, and fully expired entries must remain distinguishable;
- preserve the documented metrics semantics;
- refresh work must only be requested when appropriate;
- boundary timestamps must behave consistently;
- add regression coverage for the bug.

Do not redesign the cache. Find and preserve the existing contract.
