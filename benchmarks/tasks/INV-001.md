# INV-001 — Make config-path resolution consistent

A user reported that `load_config_path()` behaves differently from other path
handling in this repository when configuration paths come from Windows-oriented
environment values.

Fix the inconsistency.

Requirements:

- preserve the existing public function signatures;
- keep existing POSIX behavior;
- support the path forms the repository already claims to support;
- do not add a dependency;
- add or update regression tests;
- avoid introducing a second path-normalization policy if the repository already has
  one.

Investigate the repository before deciding where the fix belongs.
